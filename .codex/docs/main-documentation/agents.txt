## [Agent protocol](#agent-protocol)

1. Prefer `*.llm.md` companions — plain-text extract + metadata for each source doc.
2. Read [llms.txt](llms.txt) for the complete local file index (1371 entries).
3. [sitemap.xml](sitemap.xml) lists paths for crawlers and static hosting.
4. For Next.js implementation, use [02-development/nextjs/official-docs/llms.txt](02-development/nextjs/official-docs/llms.txt).
5. For Google Analytics / GTM / Ads tagging, use [02-development/integrations/google/agents.txt](02-development/integrations/google/agents.txt).
6. For consent / Usercentrics, use [02-development/integrations/consent-management/usercentrics/agents.txt](02-development/integrations/consent-management/usercentrics/agents.txt).
7. For marketing science concepts (CEP, mental availability), start at [03-marketing-science/vitenskap/index.mdx](03-marketing-science/vitenskap/index.mdx).
8. Do not commit or expose files under `02-development/_secrets/`.
9. For Motion / Framer Motion animations, use [25-motion/agents.txt](25-motion/agents.txt) and [25-motion/sitemap.md](25-motion/sitemap.md).
